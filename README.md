# Armenian liturgical audio

Spoken reading introductions (short, no chapter and verse), gospel captions, prayers, apocrypha passages and non-biblical lections for the liturgical calendar site. AI generated speech (ElevenLabs, model eleven_v4, voice Dj7pgiuloVNRtSboSnjm), loudness-normalised to -19.6 LUFS. `audio/index.json` maps clip ids and scripture citation keys (`Book|c1:v1-c2:v2`) to files under `clips/` (content-hash names).

Canonical Bible readings are not voiced here. Rebuilt by the digitization project (`pipeline/s90_audio_repo.py`).
